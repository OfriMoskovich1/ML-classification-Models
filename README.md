This repository contains implementations of machine learning classification algorithms applied to two different types of datasets, tabular data and image data. The overarching goal is to build reliable predictive models and evaluate their performance. The project uses a tabular dataset of dry beans to classify bean types based on morphological features, and a pre processed and filtered image dataset of clothing items. The methodologies include data preprocessing, normalization, and the implementation of various models, alongside evaluating the models using accuracy metrics and performance analysis.
